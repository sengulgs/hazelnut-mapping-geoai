# 🌐 Google Earth Engine Application

## Overview

<div align="justify">

An interactive **Google Earth Engine (GEE) application** was developed to support satellite-based visualization, analysis, and monitoring of hazelnut orchards in **Sakarya Province, Turkey**.

</div>

<div align="justify">

The application provides a web-based interface for exploring multi-temporal satellite imagery and environmental indicators without requiring users to directly interact with the Google Earth Engine code environment.

</div>

<div align="justify">

It complements the machine learning and deep learning components of the study by providing an interactive platform for visual exploration of satellite-derived information.

</div>

**Launch the application:** [Sakarya Hazelnut Frost Monitoring](https://ee-smhsng2.projects.earthengine.app/view/sakarya-hazelnut-frost-monitoring)

---

## 🗺️ Spatial Analysis

<div align="justify">

The application supports parcel-based and user-defined spatial analysis within Sakarya.

</div>

<div align="justify">

Users can interactively select and examine:

</div>

- Frost-affected hazelnut parcels
- User-defined points
- User-defined rectangles and polygons

<div align="justify">

These selection tools enable satellite observations to be explored at parcel scale or for a custom area of interest.

</div>

---

## 🛰️ Satellite Imagery

<div align="justify">

The application provides access to multi-temporal satellite observations used for agricultural and environmental monitoring.

</div>

<div align="justify">

Available visualization products include:

</div>

- **RGB**
- **False Color**
- **NDVI**
- **SAVI**
- **EVI**

<div align="justify">

Users can compare satellite observations from different dates to examine temporal changes across hazelnut orchards and surrounding land-cover types.

</div>

---

## 🌱 Vegetation Monitoring

<div align="justify">

Vegetation indices are used to monitor the seasonal development and condition of hazelnut orchards.

</div>

<div align="justify">

The application supports:

</div>

- **Normalized Difference Vegetation Index (NDVI)**
- **Soil Adjusted Vegetation Index (SAVI)**
- **Enhanced Vegetation Index (EVI)**

<div align="justify">

Multi-temporal observations enable vegetation activity to be evaluated throughout the hazelnut phenological cycle.

</div>

---

## 📈 Time-Series Analysis

<div align="justify">

Interactive time-series analysis enables users to investigate temporal changes in vegetation conditions for selected areas.

</div>

<div align="justify">

This functionality supports the examination of:

</div>

- Seasonal vegetation development
- Phenological changes
- Temporal vegetation variability
- Abnormal changes in vegetation condition

<div align="justify">

The time-series component provides a direct connection between the phenological analyses performed in the study and their spatial visualization.

</div>

---

## ❄️ Frost Monitoring

<div align="justify">

The application includes functionality for investigating vegetation responses associated with **spring frost events**.

</div>

<div align="justify">

Satellite-derived vegetation indices can be compared across relevant observation periods to examine changes in vegetation condition before and after frost events.

</div>

<div align="justify">

This functionality demonstrates the potential of Earth observation data for agricultural monitoring beyond land-cover classification.

</div>

---

## 🖥️ Application Interface

<div align="justify">

The application was designed to provide an accessible interface for users without requiring programming experience.

</div>

<div align="justify">

Interactive controls enable users to:

</div>

- Select frost-affected orchard parcels
- Draw custom points, rectangles, or polygons
- Select satellite acquisition dates
- Change visualization products
- Compare 2024 and 2025 observations in a linked split-map view
- Generate time-series information
- Explore parcel-level satellite information

<div align="justify">

The interface brings the main satellite-based monitoring components of the research into a single web environment.

</div>

---

## 🔗 Application Access

<div align="justify">

The application is publicly available at **[Sakarya Hazelnut Frost Monitoring](https://ee-smhsng2.projects.earthengine.app/view/sakarya-hazelnut-frost-monitoring)**. It runs in a web browser and does not require access to the application source code.

</div>

---

## 🔑 Key Capabilities

<div align="justify">

The GEE application integrates the main monitoring components of the study into an interactive environment, including:

</div>

- Multi-temporal satellite visualization
- Parcel-based and custom-geometry exploration
- Linked split-map comparison
- Vegetation index analysis
- Phenological monitoring
- Time-series analysis
- Frost assessment

<div align="justify">

The application demonstrates how the satellite-based methods developed in the research can be translated into an accessible **web-based monitoring and decision-support environment**.

</div>
