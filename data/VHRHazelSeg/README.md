# VHRHazelSeg

<div align="justify">

VHRHazelSeg is the semantic-segmentation dataset developed for detailed hazelnut and land-cover mapping in a nearly 110 km² pilot area. Ground-truth labels were generated with a GEOBIA-assisted workflow and manually reviewed before patch generation.

</div>

## Dataset summary

- 5,873 RGB image-mask pairs;
- 512 × 512 pixels per patch;
- 12.5% overlap (64 pixels) in both directions;
- 4,111 training patches;
- 881 validation patches; and
- 881 test patches.
