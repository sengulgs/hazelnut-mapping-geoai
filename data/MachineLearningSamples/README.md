# Machine-Learning Reference Samples

<div align="justify">

The province-scale reference database contains **6,687 polygon samples** representing 11 LULC classes across Sakarya Province. The polygons cover approximately **71.3 km²** and were compiled from field observations, LPIS information, expert interpretation, vegetation indices, multi-temporal Sentinel-2 imagery, and very-high-resolution basemaps.

</div>

<div align="justify">

The samples were divided with a spatially balanced and class-aware stratified strategy:

</div>

- 80% training;
- 20% independent testing; and
- preservation of class proportions by both polygon count and represented area where possible.

<div align="justify">

The class-level distribution is provided in [`sample_split_distribution.csv`](sample_split_distribution.csv).

</div>
