# Data Resources

<div align="justify">

This directory documents the data sources and provides machine-readable metadata extracted from the thesis. Large datasets are distributed as access-controlled Google Drive packages after permission review.

</div>

## Included metadata

| File / directory | Description |
|---|---|
| [`sentinel2_bands.csv`](sentinel2_bands.csv) | Sentinel-2 band names, wavelengths, and native spatial resolutions |
| [`pleiades_neo_bands.csv`](pleiades_neo_bands.csv) | Pléiades Neo panchromatic and multispectral band metadata |
| [`hazelnut_phenology_calendar.csv`](hazelnut_phenology_calendar.csv) | phenological stages and typical monthly periods |
| [`MachineLearningSamples/`](MachineLearningSamples/) | province-scale reference-sample description and split distribution |
| [`VHRHazelSeg/`](VHRHazelSeg/) | semantic-segmentation dataset construction, class areas, and split distributions |

## Distribution policy

- Sentinel-2 imagery can be reproduced from public Copernicus collections.
- Field and interpreted reference samples are available through the access-controlled [MachineLearningSamples package](MachineLearningSamples/).
- Distributable segmentation components are available through the access-controlled [VHRHazelSeg package](VHRHazelSeg/).
- Original Pléiades Neo imagery is not redistributed.
