# Machine-Learning Scripts

<div align="justify">

Planned release scope:

</div>

- extract pixel features from the polygon reference database;
- preserve class and spatial distributions during splitting;
- run 3-fold `RandomizedSearchCV` with weighted F1;
- train Random Forest, Extra Trees, XGBoost, CatBoost, and LightGBM;
- evaluate the 72-feature and 60-feature stacks;
- export confusion matrices, metrics, and class-area estimates; and
- perform province-scale inference.

Complete published benchmark tables are already available under [`results/classification/`](../../results/classification/).
