# Deep-Learning Scripts

<div align="justify">

Planned release scope:

</div>

- load VHRHazelSeg image-mask pairs and split manifests;
- train U-Net++, DeepLabv3+, and SegFormer;
- compare MiT-B0, MiT-B1, and MiT-B2 SegFormer encoders;
- train final SE-ResNeXt50-based configurations;
- use alpha-based Focal Loss, Adam, learning-rate scheduling, and early stopping;
- export checkpoints, metrics, confusion matrices, and prediction masks; and
- run inference on new compatible RGB patches.

<div align="justify">

The full training configuration and benchmark are documented in [VHRHazelSeg and Deep Learning](../../docs/VHRHAZELSEG_DEEP_LEARNING.md).
